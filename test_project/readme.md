# DFX Reliability Test Framework

基于 pytest 的自动化可靠性测试框架，用于 DFX（Design for X）相关功能的测试验证。

## 项目简介

本框架提供自动化测试能力，针对 DFX 可靠性指标进行系统性验证，确保产品质量满足可靠性要求。

## 功能特性

### 测试用例结构
每个自动化测试案例包含三部分，均通过调用关键字实现：
- **测试前置（Precondition）**：调用 Setup 关键字，完成环境检查、资源准备、前置条件验证
- **测试步骤（Test Step）**：调用 Steps 和 Verify 关键字，完成测试操作执行、结果检查、数据记录
- **测试后置（Postcondition）**：调用 Cleanup 关键字，完成资源释放、环境恢复、数据清理

### 关键字管理
- 通用测试方法库，包含：
  - **前置条件（Setup）**：环境初始化、资源准备、依赖检查
  - **检查方法（Verify）**：断言封装、结果校验、异常判定
  - **功能关键字（Function）**：控制关键字执行的策略
    - **循环执行（Loop）**：决定其他关键字的调用次数
    - **时长执行（Duration）**：决定关键字的调用时长
    - **随机执行（Random）**：封装其他关键字进行随机调用
    - **并发执行（Concurrent）**：封装其他关键字进行并发调用
  - **测试方法关键字（Method）**：测试业务逻辑封装
    - **故障模型（Fault）**：模拟故障场景的关键字
    - **业务模型（Business）**：业务测试逻辑封装
      - **配置面模型（Config）**：配置相关业务测试
      - **数据面模型（Data）**：数据相关业务测试
    - **监控模型（Monitor）**：系统监控指标采集关键字
- 关键字可复用，支持继承和扩展

### 测试床管理
- 测试床配置管理，包含：
  - 工具依赖（测试工具、脚本、环境）
  - 硬件环境依赖（设备、仪器、网络）
  - 部署方式依赖（部署配置、镜像、参数）
- 测试床与测试集绑定，支持多测试床并行

### 测试集管理
- 测试集组织结构，支持分类、分组
- 测试集可配置，包含测试用例集合定义
- 支持测试集间的依赖关系管理

### 执行管理
- 单个测试用例执行
- 失败用例单独重新执行
- 自定义测试用例集合执行
- 测试集执行（按测试床选择执行环境）

### 测试报告管理
- 测试结果统计：
  - 成功案例数
  - 失败案例数
  - 跳过案例数
- 失败案例详情：
  - 失败原因
  - 失败位置
  - 相关日志
- 支持 HTML 报告导出

### 配置管理
- 案例通用配置集中管理，支持：
  - 全局配置（框架级参数、环境配置）
  - 测试集配置（关联测试集的配置项）
  - 测试床配置（测试床通用参数）
- 配置文件格式支持 YAML/JSON/INI
- 配置项可继承、可覆盖
- 支持环境变量和命令行参数注入

## 安装说明

```bash
pip install pytest
pip install pytest-html
pip install -r requirements.txt
```

## 使用方法

### 运行所有测试
```bash
pytest
```

### 运行指定测试文件
```bash
pytest tests/
```

### 运行指定测试用例
```bash
pytest tests/test_xxx.py::test_case_name
```

### 运行失败用例
```bash
pytest --lf
```

### 生成测试报告
```bash
pytest --html=reports/report.html --self-contained-html
```

## 目录结构

```
.
├── config/              # 配置管理目录
│   ├── global.yaml      # 全局配置
│   ├── testbed_*.yaml   # 测试床配置
│   └── testsuite_*.yaml  # 测试集配置
├── keywords/            # 关键字定义目录
│   ├── __init__.py
│   ├── setup.py         # 前置条件关键字
│   ├── steps.py        # 执行步骤关键字
│   └── verify.py       # 检查方法关键字
├── testbeds/            # 测试床配置目录
│   └── *.yaml           # 测试床配置文件
├── testsuites/          # 测试集配置目录
│   └── *.yaml           # 测试集配置文件
├── tests/               # 测试用例目录
│   └── test_*.py
├── reports/             # 测试报告输出目录
├── conftest.py          # pytest配置文件
├── requirements.txt     # 依赖包
└── readme.md            # 项目说明文档
```
